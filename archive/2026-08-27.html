数据规模与结构

1,000+ deployment configurations，30+ models，多种 quantization，macOS/iOS/Windows/Android；context 256–8,192。质量评测按固定 dataset version 和 deterministic scorer，性能测试多轮重复并记录标准差。

数据生产方式

真实物理设备实验 → readiness/热状态控制 → 固定 token shape 多次重复 → 记录运行时/设备/量化/上下文元数据；质量数据通过固定 prompts、固定版本 dataset、model-blind deterministic scorer 产生。

是否依赖人工 / 专家 / 环境搭建

人工：高；专家：高（端侧推理/硬件测试）；环境搭建：极高，且包含真实手机/PC/芯片设备实验室。

可外包的数据生产或质检环节

设备采购/机房管理、benchmark lab 执行、runtime 适配、量化配置矩阵、重复测试、热状态/背景进程控制、submission QA、质量 benchmark 跑测、原始记录审核、跨设备回归。

数据处理服务商机判断

极强且很新。它明确鼓励 model provider、runtime developer、hardware team、application builder 扩充 coverage。可从“亚洲设备实验室 / 批量端侧跑测 / 新硬件与 runtime coverage”切入。

高但 License 风险显著。方法论非常值得复制，但原 Pipette 数据不适合拿来做竞争性评测服务；若产品化必须自建测量数据、测试协议和结果库。
